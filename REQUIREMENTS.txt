Cleanix - Full-Stack SaaS Platform Architecture & Functional Requirements

--------------------------------------------------------------------------------
1. EXECUTIVE SUMMARY & CORE CONCEPT
--------------------------------------------------------------------------------
Cleanix হলো একটি অন-ডিমান্ড B2B (Business-to-Business) এবং B2C (Business-to-Consumer) হাইব্রিড ক্লিনিং সার্ভিস অটোমেশন প্ল্যাটফর্ম।
এটি আবাসিক বাড়ি, বাণিজ্যিক অফিস, সংস্কারাধীন স্থান এবং স্থানান্তরযোগ্য সম্পত্তির জন্য নির্ভরযোগ্য, দ্রুত এবং উচ্চ-মানের ক্লিনিং পরিষেবা প্রদান করে।

প্ল্যাটফর্মটি শুধু একটি সাধারণ বুকিং সাইট নয়; এটি একটি সম্পূর্ণ SaaS (Software-as-a-Service) চালিত field service management ecosystem,
যেখানে গ্রাহক, পরিষেবা প্রদানকারী (ক্লিনার টিম) এবং প্রশাসকগণ নির্বিঘ্নে যোগাযোগ করেন।


--------------------------------------------------------------------------------
2. TARGET AUDIENCE & REVENUE MODEL
--------------------------------------------------------------------------------
Target Audience:
1. Residential Customers (আবাসিক গ্রাহক - B2C): যারা ব্যস্ততার কারণে বাড়ি পরিষ্কারের জন্য লোক খুঁজছেন বা ডিপ ক্লিনিং চান।
2. Commercial Customers (কমার্শিয়াল গ্রাহক - B2B): বিভিন্ন অফিস বা ব্যবসা প্রতিষ্ঠান যাদের নিয়মিত পরিচ্ছন্নতা প্রয়োজন।
3. Relocating Customers (স্থানান্তরকারী গ্রাহক - Move-in / Move-out): যারা নতুন বাসায় উঠছেন বা পুরোনো বাসা ছাড়ছেন।
4. Construction & Renovation Owners (নির্মাণ সংস্থা বা মালিক - Post-Construction): যারা রেনোভেশন বা নতুন কনস্ট্রাকশনের পর জায়গা পরিষ্কার করতে চান।

Revenue Generation Streams & Detailed Package Breakdown (গ্রাহক যা যা সেবা পাবেন):

1. BASIC PLAN - ৳6,000 / মাস (Monthly)
   [উপযুক্ত: ছোট বাসা, ২ বেডরুম অ্যাপার্টমেন্ট বা ছোট স্টার্টআপ অফিস]
   গ্রাহক যা যা সেবা পাবেন:
   - মাসে ২ বার রুটিন হোম ক্লিনিং (Bi-weekly Visit)
   - স্ট্যান্ডার্ড ফ্লোর মোছা, ভ্যাকুয়ামিং ও ডাস্টিং
   - রান্নাঘর ও বাথরুম ডিপ রিফ্রেশ (ডাস্ট রিপেলেন্ট স্প্রেসহ)
   - অনলাইন কাস্টমার সাপোর্ট ও ডিজিটাল ইনভয়েস
   - রিয়েল-টাইম সার্ভিস ট্র্যাকিং নোটিফিকেশন

2. STANDARD PLAN (POPULAR) - ৳14,000 / মাস (Monthly)
   [উপযুক্ত: মাঝারি ও বড় পরিবার, কমার্শিয়াল শোরুম ও মাঝারি অফিস স্পেস]
   গ্রাহক যা যা সেবা পাবেন:
   - মাসে ৪ বার (সাপ্তাহিক ১ বার) ডিপ ক্লিনিং সার্ভিস (Weekly Visit)
   - রান্নাঘর, বাথরুম ও ব্যালકની সম্পূর্ণ অ্যান্টি-ব্যাকটেরিয়াল স্যানিটাইজেশন
   - সোফা, কার্পেট ও মেট্রেস ড্রাক্স ভ্যাকুয়াম অ্যান্ড ড্রায়ার সার্ভিস
   - ইন্টেরিয়র গ্লাস ও উইন্ডো স্যানিটাইজিং ক্লিন
   - ২৪/৭ ডেডিকেটেড ফোন ও চ্যাট সাপোর্ট

3. PREMIUM PLAN - ৳30,000 / মাস (Monthly)
   [উপযুক্ত: বড় করপোরেট অফিস, ডুপ্লেক্স/লাক্সারি ভিলা ও হাই-অ্যান্ড কমার্শিয়াল স্পেস]
   গ্রাহক যা যা সেবা পাবেন:
   - মাসে ৮ বার (সাপ্তাহিক ২ বার) মাস্টার ক্লিনিং সার্ভিস (Bi-weekly Visit)
   - সম্পূর্ণ স্পেসের হসপিটাল-গ্রেড কেমিক্যাল অ্যান্ড স্টীম স্যানিটাইজেশন
   - ওভেন, ফ্রিজ ও কিচেন চিমনি ডিপ কেয়ার সার্ভিস (ইনক্লুডেড)
   - ফার্নিচার উড/লেদার পোলিশিং এবং ফ্লোর শাইন ট্রিটমেন্ট
   - ডেডিকেটেড ভিআইপি কনসিয়ার্জ ম্যানেজার ও রিয়েল-টাইম লাইভ জিপিএস ট্র্যাকিং
   - প্রতি সপ্তাহে বিস্তারিত কোয়ালিটি ইনসপেকশন রিপোর্ট

4. Custom Instant Estimate (One-Time Booking):
   - স্পেসের সাইজ (Square Feet), রুম সংখ্যা এবং পছন্দের অ্যাড-অন সার্ভিসের ওপর ভিত্তি করে ডাইনামিক পে-পার-সার্ভিস বিলিং।

5. Add-on Service Fees:
   - ওভেন ওয়াশ, ফ্রিজ ডিপ ক্লিন, ইন্টেরিয়র উইন্ডো ক্লিনিং, সোফা শ্যাম্পু ওয়াশ, পেট হাইজিন ট্রিটমেন্ট।

3. SYSTEM ARCHITECTURE & TECH STACK
--------------------------------------------------------------------------------
- Frontend Framework: Next.js 16 (App Router with Server Components & Actions)
- Styling & UI: Tailwind CSS v4 + Framer Motion + Lenis Smooth Scroll + Lucide React
- Database: MongoDB Atlas
- ORM / ODM Layer: Mongoose
- Authentication: NextAuth.js (Auth.js) / Clerk (Credentials, Google OAuth, Magic Link, RBAC)
- Payment Engines & Billing: Stripe API, SSLCommerz, bKash Gateway (Subscriptions, Webhooks, Dunning)
- Media & Storage: Cloudinary / Uploadthing (Before/After Proof of Work Photos)
- Communication APIs: Resend (Transactional Emails & PDF Invoices) + Twilio (SMS Dispatch Alerts)
- Validation & State: Zod, React Hook Form, Zustand / React Context

4. DATABASE SCHEMAS & DATA MODELING (MONGOOSE)
--------------------------------------------------------------------------------
1. User Schema:
   - _id: ObjectId
   - name: String (Required)
   - email: String (Unique, Required)
   - passwordHash: String (Optional for OAuth users)
   - phone: String (Required)
   - role: String (Enum: "CUSTOMER", "CLEANER", "ADMIN", Default: "CUSTOMER")
   - address: { street: String, city: String, area: String, zipCode: String, geoCoordinates: { lat: Number, lng: Number } }
   - avatarUrl: String
   - createdAt, updatedAt: Date

2. Booking Schema:
   - _id: ObjectId
   - bookingNumber: String (Unique, e.g., "CLN-2026-8891")
   - customerId: ObjectId (Ref: User)
   - cleanerTeamId: ObjectId (Ref: User, Optional until assigned)
   - serviceType: String (Enum: "RESIDENTIAL", "COMMERCIAL", "DEEP_CLEAN", "MOVE_IN_OUT", "POST_CONSTRUCTION")
   - propertyDetails: { sqft: Number, bedrooms: Number, bathrooms: Number }
   - selectedAddons: [{ name: String, price: Number }]
   - totalAmount: Number (Required)
   - status: String (Enum: "PENDING", "ASSIGNED", "EN_ROUTE", "IN_PROGRESS", "COMPLETED", "CANCELLED")
   - scheduledDate: Date (Required)
   - timeSlot: String (e.g., "09:00 AM - 11:00 AM")
   - paymentStatus: String (Enum: "UNPAID", "PAID", "REFUNDED")
   - paymentMethod: String (Enum: "STRIPE", "SSLCOMMERZ", "BKASH", "CASH_ON_DELIVERY")
   - createdAt, updatedAt: Date

3. Subscription Schema:
   - _id: ObjectId
   - customerId: ObjectId (Ref: User)
   - planType: String (Enum: "BASIC", "STANDARD", "PREMIUM")
   - monthlyPrice: Number
   - stripeSubscriptionId: String
   - status: String (Enum: "ACTIVE", "PAST_DUE", "CANCELLED")
   - visitsPerMonth: Number
   - remainingVisits: Number
   - currentPeriodStart: Date
   - currentPeriodEnd: Date

4. ProofOfWork Schema:
   - _id: ObjectId
   - bookingId: ObjectId (Ref: Booking)
   - cleanerId: ObjectId (Ref: User)
   - beforePhotos: [String] (Cloudinary URLs)
   - afterPhotos: [String] (Cloudinary URLs)
   - notes: String
   - customerRating: Number (1-5)
   - customerReview: String
   - createdAt: Date

5. API ROUTE ARCHITECTURE & SERVER ACTIONS
--------------------------------------------------------------------------------
- Auth Routes:
  - POST /api/auth/register (User registration)
  - POST /api/auth/[...nextauth] (NextAuth callback & session management)

- Pricing & Booking Routes:
  - POST /api/pricing/estimate (Calculates instant quote based on sqft & rooms)
  - POST /api/bookings (Create new booking & lock time slot)
  - GET  /api/bookings/my-bookings (Fetch customer booking history)
  - PATCH /api/bookings/[id]/status (Update booking status by Cleaner or Admin)

- Admin & Dispatcher Routes:
  - GET  /api/admin/dispatch (Fetch visual schedule calendar & cleaner availability)
  - PATCH /api/admin/assign-cleaner (Assign cleaner team to specific booking)
  - GET  /api/admin/analytics (Fetch daily revenue, total bookings, active subscriptions)

- Payment & Webhook Handlers:
  - POST /api/payments/stripe/checkout (Create Stripe checkout session)
  - POST /api/webhooks/stripe (Listen for invoice.payment_succeeded, customer.subscription.deleted)
  - POST /api/payments/sslcommerz/init (Initialize SSLCommerz session)
  - POST /api/payments/bkash/create (Initialize bKash payment)

7. CORE FUNCTIONAL ALGORITHMS & LOGIC
--------------------------------------------------------------------------------
1. Dynamic Pricing Calculation Formula:
   Base Service Fee (৳1,500) + (SqFt * ৳2.5) + (Bedrooms * ৳500) + (Bathrooms * ৳400) + Selected Addons

2. Concurrency & Time-Slot Availability Lock:
   - Atomic database reservation for 10 minutes during payment checkout.
   - Prevents double-booking of cleaner teams for identical dates and time slots.

3. Automated Notification Triggers:
   - Booking Confirmed -> Email PDF Invoice to Customer (Resend API)
   - Cleaner Dispatched -> SMS alert with estimated arrival time (Twilio API)
   - Job Completed -> Push notification & Email asking for 5-star review
